# main.css

Global styles: CSS custom properties for the color palette (dark theme by default), page layout, on-screen piano key styling, the patch-editor grid, and the timeline/transport view. `.piano-key` uses `touch-action: none` and a 40–48px minimum size so it works as a touch target, not just a mouse target; `.timeline-block` does the same for drag/resize. `.timeline-track-header`'s width (120px) is duplicated as `TRACK_HEADER_WIDTH` in [timeline.js](../js/ui/timeline.md) — keep them in sync. As more views are added, prefer one stylesheet per major UI area over growing this file indefinitely; the timeline rules are already large enough that splitting them into `css/timeline.css` would be reasonable the next time this file is touched.
