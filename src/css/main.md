# main.css

Global styles: CSS custom properties for the color palette (dark theme by default), page layout, on-screen piano key styling, the patch-editor grid, the timeline/transport view (including the loop-region overlay), the piano-roll note editor, and the mixer channel strips. `.piano-key`/`.timeline-block`/`.piano-roll-note` all use `touch-action: none` so drag/resize works as a touch target, not just a mouse target. `.timeline-track-header`'s width (120px) is duplicated as `TRACK_HEADER_WIDTH` in [timeline.js](../js/ui/timeline.md) — keep them in sync. As more views are added, prefer one stylesheet per major UI area over growing this file indefinitely; the timeline + piano-roll rules are already large enough that splitting them into their own files would be reasonable the next time this file is touched.
