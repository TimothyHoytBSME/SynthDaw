# main.css

Global styles: CSS custom properties for the color palette (dark theme by default), page layout, the patch-editor grid, the timeline/transport view (including the loop-region overlay), the piano-roll note editor, the mixer channel strips, and the header's project controls. `.timeline-block`/`.piano-roll-note`/`.timeline-ruler` use `touch-action: none` so drag/resize works as a touch target, not just a mouse target. `.timeline-track-header`'s width (120px) is duplicated as `TRACK_HEADER_WIDTH` in [timeline.js](../js/ui/timeline.md) — keep them in sync; `.piano-roll-grid`'s 20px row period is likewise duplicated as `ROW_HEIGHT` in [pianoRoll.js](../js/ui/pianoRoll.md).

**Phase 10 touch pass:** every small icon/toggle button (`.timeline-track-remove`, `.timeline-block-remove`, `.mixer-toggle`, `.mixer-effect-header button`, `.project-controls button`, `.transport-bar button`, etc.) has an explicit `min-width`/`min-height` (24–40px) rather than shrinking to fit its glyph — measured on a real mobile viewport before and after (`timeline-track-remove` went from 12×14px to 28×28px, for example) rather than guessed. Resize-handle widths (`.timeline-block-resize`, `.piano-roll-note-resize`) were widened for the same reason. `.piano-roll-note`'s controls remain the most cramped in the app (~18px) since the piano roll has no zoom control yet to trade off — see the "Known limitation" note in [pianoRoll.md](../js/ui/pianoRoll.md).

As more views are added, prefer one stylesheet per major UI area over growing this file indefinitely; the timeline + piano-roll rules are already large enough that splitting them into their own files would be reasonable the next time this file is touched.

Phase 14–15 additions: the patch editor's sectioned grid (`.patch-section`, `.patch-readout`), selection highlights (`.timeline-track-header--selected`, `.timeline-block--selected`, `.mixer-strip--selected`), the `.timeline-view-bar`/`.block-toolbar` rows, mini note previews (`.timeline-block-note`), and lane gridlines driven by the per-lane `--bar-px`/`--beat-px` custom properties. Track headers are sticky (z-index above blocks and the playhead).
