# audioEngine.js

Owns the single `AudioContext` and master gain node (lazily created on the first `note:on`, so we don't trip the browser's autoplay-gesture policy). Subscribes to `note:on`/`note:off` on the shared [eventBus](../core/eventBus.md) and forwards them to a [synthEngine](./synthEngine.md) instance, which owns polyphony/voice management. Also holds the current [patch](./patch.md) and exposes `getPatch()`/`setPatch()` for UI consumers like [patchEditor.js](../ui/patchEditor.md). `ensureAudioContext()`/`getMasterGain()` are the public entry points other modules (e.g. [transportController.js](../core/transportController.md)) use to get at the same context/output instead of creating their own.

`initAudioEngine()` must be called once at startup before any `note:on` events are emitted. `ensureContext()` also resumes a suspended context on every note-on, which covers Chrome's per-tab autoplay suspension after inactivity. The synth engine itself isn't created until `ensureContext()` runs (it needs the context/master gain to exist first), so `setPatch()` calls before the first note-on only update `currentPatch` — that's fine, since the engine reads it via `synthEngine.setPatch(currentPatch)` once it's constructed.
