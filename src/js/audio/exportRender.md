# exportRender.js

Offline (non-realtime) render of the whole project to an `AudioBuffer`, for [wavEncoder.js](./wavEncoder.md) to turn into a downloadable file. Stands up a *second*, throwaway [synthEngine](./synthEngine.md) + [mixer](./mixer.md) against an `OfflineAudioContext` instead of touching the live one — this works with zero DSP-code duplication specifically because every audio module in this app (`synthEngine.js`, `mixer.js`, `effectChain.js`, everything in `effects/`) takes its `AudioContext` as a constructor parameter rather than importing a global one. If that ever changes (e.g. a module starts calling [audioEngine.js](./audioEngine.md)'s `ensureAudioContext()` directly instead of receiving a context), offline export breaks silently by rendering into the wrong graph — keep audio modules context-agnostic.

Render length is computed from the *last* note's end across every track/block (`projectEndBeat`), plus a fixed `RELEASE_TAIL_SECONDS` (2s) so a note's release/reverb tail isn't truncated, floored at `MIN_DURATION_SECONDS` (1s) for an empty project. Uses the current live [patch](./patch.md) (passed in by the caller, [projectControls.js](../ui/projectControls.md)) for every track, since there's no per-track patch yet — same standing deviation as live/sequenced playback.
