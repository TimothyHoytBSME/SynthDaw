# presets.js

Built-in starting-point patches: instruments (Init, Saw Lead, Soft Pad, Pluck, Sub Bass, Keys) and drums/effects built on the noise oscillator and pitch envelope (Kick, Snare, Closed Hat, Open Hat, Tom, Zap, Noise Sweep). Suggested notes: Kick C2, Snare D3, Tom around C3, hats anywhere. Measured offline at those notes: Kick peak 0.89 (sweeps ~150→50 Hz), Snare 0.67, hats 0.41, all within the range of the instrument presets. Each preset is stored only as its *differences* from the default patch, and `createPresetPatch(name)` expands it with [patch.js](./patch.md)'s `normalizePatch`, so adding a patch field never requires touching every preset. `PRESET_NAMES` drives the dropdown in [patchEditor.js](../ui/patchEditor.md). Loading a preset replaces the selected track's patch via `setTrackPatch` (undoable).
