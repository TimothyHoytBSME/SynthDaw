# voice.js

One sounding note: `createVoice(audioContext, destination, note, velocity, patch, { bendCents, tempo })` builds sources (each with its own level gain) -> shared biquad filter -> `envGain` (amp ADSR, 0..1) -> `levelGain` (`patch.gain * velocity/127`, plus tremolo) -> destination. It returns `{ patch, start(atTime), stop(immediate, atTime), refresh(), setBend(cents), onEnded(callback) }`.

- **Sources:** pitched oscillators get `detune = octave*1200 + detune + bend` cents (octave is done in cents so bend, LFO and the pitch envelope share one param). Type `"noise"` is a looping 2 s white-noise `AudioBufferSourceNode` (one buffer per context, cached in a `WeakMap`), started at a random offset so overlapping hits don't phase. Noise ignores octave, detune, bend, pitch LFO and the pitch envelope.
- **Pitch envelope** (`patch.pitchEnvelope`, skipped when `amount` is 0): every pitched source starts `amount` semitones off and glides back with `setTargetAtTime`, time constant `decay / 5`, so `decay` is roughly when the sweep is done. For kicks, toms and zaps.
- The filter envelope sweeps `cutoff -> cutoff + envAmount`, following the filter ADSR.
- **LFO rate** is `patch.lfo.rate`, or `1 / syncedSeconds(lfo.sync, tempo)` when synced. The tempo is fixed per voice (from the engine at note start).
- **LFO** is built lazily (`ensureLfo`): at start if `depth > 0`, or later if a live edit turns the depth up. Targets: `pitch` -> pitched sources' `detune`; `filter` -> `filter.frequency`; `amp` -> `levelGain.gain` (base `level*(1-d)`, LFO `±level*d`), which *multiplies* the enveloped signal so it can't sound after the release.
- **Live edits (`refresh()`):** the voice keeps the track's patch object and a JSON snapshot of what it last applied. `refresh()` diffs the two and moves only what changed, smoothed (15 ms): oscillator mix, wave (between pitched shapes; to/from noise needs a new note), octave/detune, filter type/resonance, LFO rate/depth/target, volume. Enveloped params (filter cutoff/env amount/sustain, amp sustain) are retargeted only while the note is held, via `retargetHeld`, which re-adds an already-scheduled release (`cancelAndHoldAtTime` removes it). Voices scheduled but not yet started (≤100 ms lookahead) only take the non-enveloped changes. Attack/decay times and the pitch envelope apply from the next note.
- **Release must use `cancelAndHoldAtTime`:** sequenced notes schedule their release long in advance, so reading `param.value` synchronously would capture the wrong value. See the comment on `scheduleRelease`.
- `stop(true)` is a fast (~20ms) release used for voice stealing and transport cancel. Sources are stopped at release end + a short tail.
- The split into `envGain` and `levelGain` (previously one gain with peak = level) was verified bit-identical on every Neon Tide/Riptide voice.
