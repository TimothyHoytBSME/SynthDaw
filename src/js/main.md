# main.js

App bootstrap — now `async` because startup tries to load a saved project from IndexedDB ([persistence.js](./core/persistence.md)) before rendering anything that depends on it. Initializes the audio engine, renders the piano-trigger, MIDI-status, patch-editor, timeline, mixer, and project-controls UI, and kicks off `initMIDIInput()`. Owns the one `Project` instance (loaded, or freshly created with a default track if nothing was saved) and hands it to `transportController.js` via `setProject()` so playback can find the tracks/blocks/notes to schedule.

`renderProjectUI()` (clears and re-renders the timeline/mixer containers) exists so [projectControls.js](./ui/projectControls.md)'s New/Import — and, since Phase 12, [history.js](./core/history.md)'s undo/redo — can force a full re-render after the project object is mutated wholesale; it's passed down as a callback rather than each caller reaching back into `main.js` itself. Also wires up `initHistory()` and `initKeyboardShortcuts()` (Space to play/pause, Ctrl/Cmd+Z to undo). Keep this file thin otherwise — it should only wire modules together, never contain audio or UI logic itself.
