# main.js

App bootstrap — now `async` because startup tries to load a saved project from IndexedDB ([persistence.js](./core/persistence.md)) before rendering anything that depends on it. Initializes the audio engine, renders the piano-trigger, MIDI-status, patch-editor, timeline, mixer, and project-controls UI, and kicks off `initMIDIInput()`. Owns the one `Project` instance (loaded, or freshly created with a default track if nothing was saved) and hands it to `transportController.js` via `setProject()` so playback can find the tracks/blocks/notes to schedule.

`renderProjectUI()` (clears and re-renders the timeline/mixer containers) exists so [projectControls.js](./ui/projectControls.md)'s New/Import can force a full re-render after [project.js](./core/project.md)'s `replaceProjectContents()` mutates the project in place — it's passed down as the `onReplaced` callback rather than each UI module reaching back into `main.js` itself. Keep this file thin otherwise — it should only wire modules together, never contain audio or UI logic itself.
