# projectControls.js

Seven controls in the header: **Undo**/**Redo** ([history.js](../core/history.md), disabled via a `disabled` attribute kept in sync with `history:changed` events rather than always-enabled), **New Project** (confirms, then replaces the current project's contents with an empty one plus a default track), **Export JSON** (also on Ctrl/Cmd+S via the `shortcut:export-json` event; downloads `synthdaw-project.json` via a blob URL — the manual, portable backup/sharing path), **Export WAV** (renders the whole project offline via [exportRender.js](../audio/exportRender.md) and downloads the result as a real audio file via [wavEncoder.js](../audio/wavEncoder.md) — disables itself and shows "Rendering… N%" for the render's duration, since it's not instant), **Import JSON** (hidden file input triggered by a visible button, parses and replaces), and a status readout reflecting `project:changed`/`project:saved` from the [eventBus](../core/eventBus.md) (via [persistence.js](../core/persistence.md)'s autosave).

New/Import both call `replaceProjectContents()` ([project.js](../core/project.md)) rather than swapping to a new object — every other module ([timeline.js](./timeline.md), [mixer.js](./mixer.md), `transportController.js`) holds a reference to the *original* project object, so mutating it in place is what lets `onReplaced()` (passed in by `main.js`, which just re-renders the timeline/mixer into cleared containers) work without re-wiring every module's project reference. Audio needs no special handling: the mixer reconciles itself against the replaced data on the resulting `project:changed` (see [audioEngine.js](../audio/audioEngine.md)).

**Load Demo…** (after New Project) is a `<select>` listing every song in [demos.js](../demo/demos.md) (each option's tooltip is the demo's description). Picking one confirms, then replaces the project with that demo's `create()` result the same way New/Import do. The picker then resets to its placeholder, so the same demo can be picked again. Undo restores the previous project.
